# Vayyar

> Vayyar Imaging is an Israeli 4D imaging radar company. Its radio-frequency sensor-on-chip powers Vayyar Care (privacy-safe fall detection and activity monitoring for senior care), in-cabin automotive sensing for OEMs, and the Walabot product line — including the Walabot DIY wall scanner and the Walabot Maker/Creator/Developer packs, which expose the programmable Walabot API device SDK (imaging, radar/target tracking, breathing monitoring, and raw signal data) on Windows, Linux, and Raspberry Pi.

Vayyar has no public web (HTTP) API. Its developer surface is the Walabot device SDK: a local C API with Python/C#/Matlab bindings, documented at api.walabot.com and installed from vendor-hosted SDK installers.
